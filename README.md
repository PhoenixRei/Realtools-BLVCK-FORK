# Realtools: BLVCK FORK

A revived and expanded version of the original Realtools extension for Horse Reality.

Realtools: BLVCK FORK restores beloved features from the original extension, improves existing tools, and adds modern quality-of-life improvements for horse and stable management.

> This build is an unofficial community modification and is not affiliated with Horse Reality or the original Realtools maintainer.

## Features

### Improved Horse Information

- Optional redesigned Passport and Owner's Notes cards.
- The redesigned Info UI can be enabled or disabled in Settings at any time.
- A more organic Passport layout, including owner, breeder, breed, age, sex, height, predicates, birthday, location, and life number.

### Enhanced Stats Tab

- A refreshed Stats tab design, with Genetic Potential displayed directly alongside the other horse statistics.
- Conformation, Genetic Potential, Discipline GP, Health quality totals.
- Discipline GP values and percentages.
- Best and Worst results for Conformation Shows and Competitions.
- Expandable result lists with improved table layouts.

### Presets and Placeholders

- Create and manage presets for Name, Tagline, Private Notes, and Public Notes.
- Use placeholders for horse data, scores, GP, Discipline GP, Conformation, Health, and more.
- Matching presets preserve historical score extremes:
  - Highest Score can only increase.
  - Lowest Score can only decrease.
  - Breed Total, RNG, and score range are recalculated automatically.

## Installation

### Chrome, Edge, and other Chromium-based browsers

1. Download the latest ZIP file from the [Releases](../../releases) page.
2. Extract the ZIP into a separate folder.
3. Open `chrome://extensions` in your browser.
4. Enable **Developer mode**.
5. Click **Load unpacked**.
6. Select the extracted folder containing `manifest.json`.

After installing the extension, reload any open Horse Reality pages.

## Privacy

Realtools: BLVCK FORK does not collect or send data to third-party services. It does not request access to passwords, cookies, browsing history, clipboard, downloads, or account credentials.

The extension reads Horse Reality page data only to provide its features and communicates only with Horse Reality to load horse-tab data. Private and Public Notes presets are stored locally; settings and Name/Tagline presets are stored in browser sync storage.
